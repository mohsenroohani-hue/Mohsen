# استخراج مصوبات شورای عالی شهرسازی و معماری ایران

ابزاری برای دریافت **همهٔ** مصوبات شورای عالی شهرسازی و معماری ایران از پایگاه
مرکز پژوهش‌های مجلس و تبدیل آن‌ها به فایل‌های اکسل، مرتب‌شده **بر اساس زمان** و
**بر اساس شهر**، به‌همراه **متن کامل** هر مصوبه.

منبع: <https://rc.majlis.ir/fa/law/search?lu_approve_reference=lar15>

---

## ⚠️ نکتهٔ مهم دربارهٔ اجرا

این مخزن در محیطی ساخته شده که **دسترسی شبکه به `rc.majlis.ir` بسته است**؛
بنابراین داده‌ها هنوز دریافت نشده‌اند. کد کامل، آزموده و آمادهٔ اجراست —
کافی است آن را روی رایانه‌ای با دسترسی به اینترنت اجرا کنید.

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

دریافت داده و ساخت اکسل در یک مرحله:

```bash
python -m majlis_lar15.cli all --save-html
```

اجرای گام‌به‌گام:

```bash
python -m majlis_lar15.cli scrape --save-html     # فقط دریافت
python -m majlis_lar15.cli build  --per-file 150  # فقط ساخت اکسل
```

آزمایش سریع با سه صفحهٔ نخست:

```bash
python -m majlis_lar15.cli all --max-pages 3
```

### گزینه‌ها

| گزینه | توضیح |
|---|---|
| `--out` | پوشهٔ خروجی (پیش‌فرض `out`) |
| `--max-pages` | تعداد صفحات فهرست؛ `0` یعنی همه |
| `--delay` | مکث میان درخواست‌ها (پیش‌فرض ۱٫۲ ثانیه) |
| `--save-html` | ذخیرهٔ HTML خام برای تحلیل دوباره بدون دریافت مجدد |
| `--per-file` | تعداد مصوبه در هر فایل اکسلِ متن کامل (پیش‌فرض ۱۵۰) |
| `--force` | نادیده گرفتن داده‌های پیشین و شروع از نو |

## خروجی‌ها

```
out/
├── مصوبات_شورای_عالی_شهرسازی_فهرست.xlsx
├── مصوبات_شورای_عالی_شهرسازی_متن_کامل_01_از_NN.xlsx
├── مصوبات_شورای_عالی_شهرسازی_متن_کامل_02_از_NN.xlsx
├── …
├── متن_خام/            یک فایل .txt برای هر مصوبه (پشتیبان)
├── داده_خام.jsonl      دادهٔ خام ماشین‌خوان
└── html/               صفحات خام (با ‎--save-html‎)
```

### فایل فهرست

| برگه | محتوا |
|---|---|
| راهنما | آمار کلی و توضیح فایل‌ها |
| **بر اساس تاریخ** | کل مصوبات، مرتب بر حسب تاریخ تصویب |
| **بر اساس شهر** | همان فهرست، مرتب بر حسب نام شهر (الفبای فارسی) و سپس تاریخ |
| آمار شهرها | تعداد مصوبهٔ هر شهر، نخستین و آخرین تاریخ |
| آمار سال‌ها | تعداد مصوبه در هر سال شمسی |

ستون‌ها: ردیف، شناسه، عنوان، شهر، استان، تاریخ شمسی، سال، ماه، تاریخ میلادی،
تعداد نویسهٔ متن، **فایل متن کامل**، پیوند.

ستون «فایل متن کامل» نشان می‌دهد متن هر مصوبه در کدام فایل اکسل است.

### فایل‌های متن کامل

هر سلول اکسل حداکثر **۳۲٬۷۶۷ نویسه** می‌پذیرد. متن‌های بلندتر به بخش‌های
۳۰٬۰۰۰ نویسه‌ای شکسته و در **ردیف‌های پیاپی** ذخیره می‌شوند؛ ستون‌های
«شماره بخش» و «تعداد بخش» ترتیب را مشخص می‌کنند. با چسباندن بخش‌ها به ترتیب،
متن اصلی بی‌هیچ کم‌وکاست بازسازی می‌شود — این موضوع در آزمون‌ها بررسی می‌شود.

مصوبات به چند فایل تقسیم می‌شوند (`--per-file`) تا هیچ مصوبه‌ای حذف نشود و
فایل‌ها در اکسل به‌راحتی باز شوند.

## ویژگی‌ها

- **ادامهٔ کار پس از قطعی**: داده در `داده_خام.jsonl` ذخیره می‌شود؛ اجرای
  دوباره فقط مصوبات باقی‌مانده را می‌گیرد.
- **تلاش مجدد** با تأخیر نمایی هنگام خطای شبکه.
- **تشخیص شهر** از عنوان و متن با فهرست ۵۵۰+ شهر ایران و الگوهای بافتی
  («طرح جامع شهر X»، «محدوده و حریم X»، «شهرستان X» و …).
- **تبدیل تاریخ شمسی به میلادی** و پشتیبانی از قالب‌های گوناگون
  (`۱۳۹۸/۰۵/۱۲`، `۱۲ مرداد ۱۳۹۸`، `1385-2-3`).
- **مرتب‌سازی الفبای فارسی**: ترتیب کدهای یونیکد با الفبای فارسی یکی نیست
  (مثلاً «پ» پس از «ی» قرار می‌گیرد)؛ این ابزار ترتیب درست را اعمال می‌کند.
- **برگه‌های راست‌به‌چپ** با سرستون ثابت و فیلتر خودکار.
- **`reparse`**: اگر ساختار سایت تغییر کند، با HTMLهای ذخیره‌شده می‌توان
  بدون دریافت دوباره، تحلیل را اصلاح کرد.

## آزمون‌ها

```bash
python -m unittest discover -s tests -v
```

۱۱ آزمون، شامل آزمون سرتاسری که بررسی می‌کند متن کامل از سلول‌های اکسل
دقیقاً و بدون افت بازسازی می‌شود.

## نمونهٔ خروجی

پوشهٔ `نمونه_خروجی/` حاوی خروجی ساخته‌شده از دادهٔ **ساختگی** است تا قالب
فایل‌ها پیش از اجرای واقعی قابل بررسی باشد.

## اگر ساختار سایت فرق داشت

تحلیلگر انعطاف‌پذیر نوشته شده (جست‌وجوی پیوندهای `/law/show/<id>`، یافتن
بلوک اصلی متن بر پایهٔ چگالی متن فارسی)، اما اگر خروجی ناقص بود:

1. با `--save-html` صفحات را ذخیره کنید.
2. `out/html/` را بررسی کنید.
3. در صورت نیاز `parse_search_page` یا `extract_body` را در
   `majlis_lar15/scraper.py` تنظیم و سپس `reparse` را اجرا کنید.

ستون «تعداد نویسه متن» در فهرست، و هشدارهای زمان اجرا (⚠)، مصوباتی را که
متنشان کوتاه یا تاریخشان یافت نشده نشان می‌دهند.
