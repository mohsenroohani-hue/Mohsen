# استخراج مصوبات شورای عالی شهرسازی و معماری ایران (lar15)

ابزار استخراج همهٔ مصوبات فهرست‌شده در
<https://rc.majlis.ir/fa/law/search?lu_approve_reference=lar15>
(«مصوبات شورای عالی شهرسازی و معماری ایران» در پایگاه مرکز پژوهش‌های مجلس)
و تبدیل آن‌ها به فایل‌های CSV مرتب‌شده **بر اساس زمان** و **بر اساس شهر**،
همراه با **متن کامل** هر مصوبه.

> ⚠️ توجه: در محیط اجرای فعلی (session ابری Claude) دسترسی شبکه به دامنهٔ
> `rc.majlis.ir` توسط سیاست شبکهٔ محیط مسدود است، بنابراین خودِ داده‌ها در این
> مخزن قرار ندارند. با اجرای دستور زیر روی هر رایانه‌ای که به سایت دسترسی دارد،
> همهٔ فایل‌های خروجی ساخته می‌شوند. (برای رفع انسداد: منوی محیط ابری در نوار
> عنوان جلسه → Edit → Network access و افزودن `rc.majlis.ir` به دامنه‌های مجاز.)

## اجرا

نیازمندی: فقط **پایتون ۳** (هیچ کتابخانهٔ بیرونی لازم نیست).

```bash
python3 tools/scrape_lar15.py --out output
```

گزینه‌های مفید:

| گزینه | کاربرد |
| --- | --- |
| `--out output` | پوشهٔ خروجی |
| `--cache .cache_lar15` | پوشهٔ ذخیرهٔ صفحات خام (اجرای دوباره را سریع و قابل‌ادامه می‌کند) |
| `--delay 1.5` | فاصلهٔ بین درخواست‌ها بر حسب ثانیه (رعایت ادب نسبت به سرور) |
| `--max-pages 500` | حداکثر تعداد صفحات فهرست |
| `--limit 20` | فقط ۲۰ مصوبهٔ اول (برای آزمایش سریع) |
| `--rows-per-part 200` | تعداد ردیف هر فایل تکه‌ای |
| `--from-cache` | بدون شبکه؛ فقط از صفحات ذخیره‌شده |
| `--self-test` | آزمون آفلاین با فایل‌های نمونه |

اگر اجرای برنامه نیمه‌کاره قطع شد، کافی است همان دستور را دوباره اجرا کنید؛
صفحاتی که قبلاً گرفته شده‌اند از cache خوانده می‌شوند و چیزی دوباره دانلود نمی‌شود.

### اگر سایت فقط از مرورگر شما باز می‌شود

می‌توانید صفحات را با مرورگر ذخیره کنید و برنامه را آفلاین اجرا کنید:

```
.cache_lar15/search_p001.html   ← صفحهٔ ۱ فهرست جست‌وجو
.cache_lar15/search_p002.html   ← صفحهٔ ۲ ...
.cache_lar15/law_802645.html    ← صفحهٔ هر مصوبه با شناسهٔ آن
```

```bash
python3 tools/scrape_lar15.py --out output --cache .cache_lar15 --from-cache
```

## خروجی‌ها

```
output/
├── lar15_by_date.csv        همهٔ مصوبات، مرتب بر اساس تاریخ تصویب
├── lar15_by_city.csv        همهٔ مصوبات، مرتب بر اساس استان → شهر → تاریخ
├── parts/lar15_part_01.csv  همان داده‌ها، تکه‌تکه (پیش‌فرض هر ۲۰۰ ردیف)
├── texts/<id>.txt           متن کامل هر مصوبه به صورت فایل مستقل
├── lar15_all.jsonl          دادهٔ خام (یک JSON در هر سطر)
├── report.txt               گزارش پوشش: تعداد کل، تاریخ/شهر تشخیص‌داده‌نشده، پراکندگی سالانه
└── failed.txt               (در صورت وجود) مصوباتی که دریافت نشدند
```

هر فایل CSV با `UTF-8 BOM` نوشته می‌شود تا در Excel فارسی درست باز شود.

### ستون‌ها

| ستون | توضیح |
| --- | --- |
| `id`, `url` | شناسه و نشانی مصوبه در سایت مجلس |
| `title` | عنوان مصوبه |
| `approval_date_jalali` | تاریخ تصویب شمسی به شکل `YYYY/MM/DD` (برای مرتب‌سازی زمانی) |
| `approval_date_gregorian` | همان تاریخ به میلادی `YYYY-MM-DD` |
| `year`, `month`, `day` | اجزای تاریخ شمسی |
| `city` | شهر تشخیص‌داده‌شده |
| `city_kind` | نوع: شهر / شهر جدید / شهرستان / روستا / منطقه / بندر |
| `province` | استان |
| `all_cities` | همهٔ شهرهای ذکرشده در عنوان (برای مصوبات چندشهری) |
| `subject_type` | نوع موضوع: طرح جامع، طرح تفصیلی، طرح هادی، ضوابط و ... |
| `approval_body` | مرجع تصویب |
| `announcement_number`, `announcement_date` | شماره و تاریخ ابلاغ |
| `status` | وضعیت (معتبر/منسوخ و ...) |
| `text_length` | طول متن کامل |
| `full_text` | **متن کامل مصوبه** |

> نکته: متن کامل به‌طور کامل داخل CSV ذخیره می‌شود. اکسل نمایش سلول را در
> ۳۲٬۷۶۷ نویسه می‌بُرد، اما فایل CSV و فایل‌های `texts/<id>.txt` متن کامل را
> بدون هیچ برشی نگه می‌دارند.

## ساختار کد

| فایل | نقش |
| --- | --- |
| `tools/scrape_lar15.py` | برنامهٔ اصلی: پیمایش صفحات، استخراج، نوشتن خروجی‌ها |
| `tools/htmlutil.py` | تحلیل HTML و استخراج متن اصلی صفحه بدون کتابخانهٔ بیرونی |
| `tools/persian.py` | نرمال‌سازی متن فارسی، خواندن تاریخ شمسی، تبدیل شمسی→میلادی |
| `tools/cityfinder.py` | تشخیص شهر/استان/نوع طرح از عنوان و متن |
| `tools/gazetteer.py` | فهرست ۳۱ استان و بیش از ۷۵۰ شهر و شهر جدید کشور |
| `tests/fixtures/` | صفحات نمونه برای آزمون آفلاین |

آزمون:

```bash
python3 tools/scrape_lar15.py --self-test
```

## چند نکته دربارهٔ استخراج

* برنامه ساختار صفحه را حدس می‌زند: پیوندهای `/fa/law/show/<id>` را از صفحات
  فهرست جمع می‌کند و در صفحهٔ هر مصوبه، بخش اصلی متن را بر اساس چگالی متن و
  پیوند پیدا می‌کند (منو، ستون کناری و پاورقی حذف می‌شوند).
* اگر روزی ساختار سایت تغییر کرد، معمولاً تغییر `SEARCH_URL` و `SHOW_RE` در
  ابتدای `tools/scrape_lar15.py` کافی است.
* پیمایش وقتی متوقف می‌شود که دو صفحهٔ پیاپی هیچ پیوند تازه‌ای نداشته باشند،
  بنابراین همهٔ صفحات تا انتها خوانده می‌شوند و مصوبه‌ای جا نمی‌ماند.
* `report.txt` تعداد مصوبات بدون تاریخ یا بدون شهر را گزارش می‌کند تا موارد
  استثنا را دستی بررسی کنید.
