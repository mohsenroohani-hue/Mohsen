# استخراج مصوبات و ذخیره در CSV

این اسکریپت همه موارد یک صفحه فهرست مصوبات را صفحه به صفحه می‌خواند، **متن کامل هر مصوبه**
(و متن پیوست‌های PDF و Word) را دریافت می‌کند و خروجی را در قالب چند فایل CSV، مرتب‌شده بر
اساس **زمان** و بر اساس **شهر**، ذخیره می‌کند.

| نام کوتاه | منبع |
|---|---|
| `mrud` | [مصوبات شورای عالی شهرسازی و معماری — mrud.ir](https://mrud.ir/approvals/%D9%85%D8%B5%D9%88%D8%A8%D8%A7%D8%AA-%D8%B4%D9%88%D8%B1%D8%A7%DB%8C%D8%B9%D8%A7%D9%84%DB%8C-%D8%B4%D9%87%D8%B1%D8%B3%D8%A7%D8%B2%DB%8C-%D9%88-%D9%85%D8%B9%D9%85%D8%A7%D8%B1%DB%8C) |
| `majlis` | [سامانه قوانین مجلس — rc.majlis.ir، جستجوی lar15](https://rc.majlis.ir/fa/law/search?lu_approve_reference=lar15&page=1) |

## اجرا

سایت‌های دولتی ایران معمولاً اتصال از خارج از ایران را نمی‌پذیرند، پس اسکریپت را روی رایانه‌ای
در داخل ایران اجرا کنید (Python 3.9 یا جدیدتر):

```bash
cd scraper
pip install -r requirements.txt
python scrape_approvals.py mrud        # مصوبات شورای عالی شهرسازی و معماری
python scrape_approvals.py majlis      # سامانه قوانین مجلس
python scrape_approvals.py "https://...آدرس هر صفحه فهرست دیگر..."
```

- خروجی در `output/mrud/csv` (یا `output/majlis/csv`) ساخته می‌شود.
- اگر اجرا قطع شد، همان دستور را دوباره اجرا کنید؛ صفحه‌ها و فایل‌های دریافت‌شده در `output/.../raw`
  ذخیره شده‌اند و دوباره دانلود نمی‌شوند و موارد ناموفق دوباره تلاش می‌شوند.
- ساخت دوباره CSVها بدون دانلود: `python scrape_approvals.py mrud --export-only`
- خواندن دوباره فهرست (مثلاً برای مصوبات جدید): `--refresh-list`

## خروجی

| فایل | محتوا |
|---|---|
| `00_summary_by_city.csv` | تعداد مصوبات هر شهر و نخستین/آخرین تاریخ |
| `01_all_by_date.csv` | همه مصوبات، مرتب بر اساس تاریخ |
| `02_all_by_city.csv` | همه مصوبات، مرتب بر اساس شهر و سپس تاریخ |
| `by_city/<شهر>.csv` | یک فایل برای هر شهر، مرتب بر اساس تاریخ |
| `by_year/<سال>.csv` | یک فایل برای هر سال، مرتب بر اساس شهر و تاریخ |

ستون‌ها: ردیف، شناسه، عنوان، شهر، تاریخ (مبنای مرتب‌سازی)، سال، تاریخ تصویب، تاریخ ابلاغ، تاریخ انتشار،
مرجع تصویب، شماره، لینک، پیوست‌ها، سایر اطلاعات (همه فیلدهای صفحه به صورت JSON)، تعداد نویسه متن،
متن کامل مصوبه.

هیچ مصوبه‌ای حذف نمی‌شود:
- فایل‌های بیشتر از ۱۰۰۰ ردیف به چند فایل `_part01`، `_part02`، … تقسیم می‌شوند
  (قابل تغییر با `--rows-per-file`؛ مقدار `0` یعنی بدون تقسیم).
- اکسل در هر خانه حداکثر ۳۲٬۷۶۷ نویسه نشان می‌دهد؛ متن‌های طولانی‌تر به‌جای کوتاه شدن
  در چند ستون «متن کامل مصوبه (بخش ۱)»، «(بخش ۲)» و … قرار می‌گیرند.
- مصوبه‌ای که شهر یا تاریخ آن تشخیص داده نشود (مثلاً آیین‌نامه‌های سراسری) با «نامشخص» می‌آید.
- پیوست‌هایی که تصویر یا PDF اسکن‌شده هستند متن قابل استخراج ندارند؛ لینک آن‌ها در ستون «پیوست‌ها» می‌ماند.
- فایل‌ها با UTF-8 (همراه BOM) ذخیره می‌شوند تا حروف فارسی در اکسل درست نمایش داده شوند.

## تشخیص تاریخ و شهر

- **تاریخ:** به ترتیب تاریخ تصویب/جلسه، تاریخ داخل عنوان (مثل «جلسه مورخ ۱۴۰۱/۰۲/۱۵»)،
  تاریخ ابلاغ، تاریخ انتشار، تاریخ کنار لینک در فهرست و در نهایت اولین تاریخ متن.
- **شهر:** از فیلد «شهر» صفحه، عبارت‌هایی مثل «شورای اسلامی شهر …» یا «طرح جامع شهر …» در عنوان،
  یا نام شهرهای شناخته‌شده (مثل «منطقه ۲۲ تهران»). املاهای مختلف یک شهر («بندرعباس» و
  «بندر عباس») یکی می‌شوند.

## اگر نتیجه درست نبود

ساختار صفحه‌های mrud.ir از خارج ایران قابل مشاهده نبود و اسکریپت با الگوهای کلی نوشته شده است.
اسکریپت هنگام اجرا گروه‌های لینک پیدا شده را چاپ می‌کند؛ اگر لینک مصوبات درست انتخاب نشده بود،
با `--link-pattern` الگوی آدرس مصوبات را مشخص کنید (مثلاً `--link-pattern "/approval/"`)
یا صفحه فهرست و یک صفحه مصوبه را از مرورگر ذخیره کنید (Ctrl+S) و بفرستید تا اسکریپت دقیق شود.
