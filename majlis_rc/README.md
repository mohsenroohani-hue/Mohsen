# استخراج مصوبات از سامانه قوانین مرکز پژوهش‌های مجلس

این اسکریپت همه نتایج جستجوی
[`rc.majlis.ir/fa/law/search?lu_approve_reference=lar15`](https://rc.majlis.ir/fa/law/search?lu_approve_reference=lar15&page=1)
را صفحه به صفحه می‌خواند، **متن کامل هر مصوبه** را دریافت می‌کند و خروجی را در قالب
چند فایل CSV، مرتب‌شده بر اساس **زمان** و بر اساس **شهر**، ذخیره می‌کند.

## اجرا

```bash
cd majlis_rc
pip install -r requirements.txt
python scrape_rc_majlis.py
```

- اگر اجرا قطع شد، همان دستور را دوباره اجرا کنید؛ صفحه‌های دریافت‌شده در `output/raw` ذخیره
  می‌شوند و دوباره دانلود نمی‌شوند. مصوباتی که دانلودشان ناموفق بوده در اجرای بعدی دوباره تلاش می‌شوند.
- برای جستجوی دیگری: `python scrape_rc_majlis.py --url "<آدرس جستجو>"`
- ساخت دوباره CSVها بدون دانلود: `python scrape_rc_majlis.py --export-only`
- سایت مجلس ممکن است دسترسی از خارج از ایران را محدود کند؛ در این صورت اسکریپت را از داخل ایران اجرا کنید.

## خروجی (`output/csv`)

| فایل | محتوا |
|---|---|
| `00_summary_by_city.csv` | تعداد مصوبات هر شهر و نخستین/آخرین تاریخ |
| `01_all_by_date.csv` | همه مصوبات، مرتب بر اساس تاریخ (سپس شهر) |
| `02_all_by_city.csv` | همه مصوبات، مرتب بر اساس شهر (سپس تاریخ) |
| `by_city/<شهر>.csv` | یک فایل برای هر شهر، مرتب بر اساس تاریخ |
| `by_year/<سال>.csv` | یک فایل برای هر سال، مرتب بر اساس شهر و تاریخ |

ستون‌ها: ردیف، شناسه، عنوان، شهر، تاریخ (مبنای مرتب‌سازی)، سال، تاریخ تصویب، تاریخ ابلاغ،
مرجع تصویب، شماره، لینک، سایر اطلاعات (همه فیلدهای صفحه به صورت JSON)، تعداد نویسه متن، متن کامل مصوبه.

هیچ مصوبه‌ای حذف نمی‌شود:
- فایل‌های بزرگ‌تر از ۱۰۰۰ ردیف به چند فایل `_part01`، `_part02`، … تقسیم می‌شوند
  (قابل تغییر با `--rows-per-file`؛ مقدار `0` یعنی بدون تقسیم).
- اکسل در هر خانه حداکثر ۳۲٬۷۶۷ نویسه نشان می‌دهد؛ متن‌های طولانی‌تر به‌جای کوتاه شدن
  در چند ستون «متن کامل مصوبه (بخش ۱)»، «(بخش ۲)» و … قرار می‌گیرند.
- مصوبه‌ای که شهر یا تاریخ آن تشخیص داده نشود با «نامشخص» در انتهای فهرست می‌آید.
- فایل‌ها با کدگذاری UTF-8 (همراه BOM) ذخیره می‌شوند تا حروف فارسی در اکسل درست نمایش داده شوند.

شهر از فیلد «شهر» صفحه یا از عنوان مصوبه (مثل «شورای اسلامی شهر …») استخراج می‌شود و
املاهای مختلف یک شهر (مثل «بندرعباس» و «بندر عباس») یکی می‌شوند.
